# IMG300 — Grid System Studio

IMG300 is an advanced computational graphic design engine for Swiss-style modular posters. It combines exact integer 2D grid allocation, quantitative multi-objective scoring heuristics, precision typography engines with baseline grid snapping, image fit and focal point preservation crop geometry, and high-dimensional layout feature extraction.

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to launch the IMG300 Alpha Testing Studio.

### Type Check

```bash
npx tsc --noEmit
```
